# 🤖 RUDRA AI

A powerful Desktop Voice Assistant built using Python.

## Features

- 🎙 Voice Recognition
- 🔊 Text to Speech
- 🌐 Wikipedia Search
- 💻 System Control
- 📄 PDF Summarizer
- 🐍 Snake Game
- 🧠 Voice Authentication
- 🖥 Beautiful HUD GUI

## Tech Stack

- Python
- PyQt5
- SpeechRecognition
- pyttsx3
- PyAutoGUI
- PyAudio
- Librosa
- Resemblyzer
- PyGame
